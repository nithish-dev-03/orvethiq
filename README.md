# Orvethiq — Monorepo Structure

## Repository Layout

```
orvethiq/
├── AGENTS.md          — Frontend agent instructions
├── README.md          — This file
├── .gitignore         — Git ignore rules
├── client/            — Frontend (Vite + React + TypeScript)
│   ├── package.json   — Frontend dependencies and scripts
│   ├── package-lock.json
│   ├── vite.config.ts — Vite configuration
│   ├── tsconfig.json, tsconfig.app.json, tsconfig.node.json
│   ├── eslint.config.js
│   ├── index.html     — HTML entry point
│   ├── src/           — Source code
│   │   ├── main.tsx   — React rendering entry
│   │   ├── App.tsx    — Main application component
│   │   ├── index.css  — Design tokens (light/dark themes)
│   │   └── App.css    — Component styles
│   │   └── assets/    — Images and SVGs
│   │       ├── hero.png
│   │       ├── react.svg
│   │       └── vite.svg
│   └── public/        — Static assets (favicon.svg, icons.svg)
│   └── dist/          — Production build output (generated by `npm run build`)
│   └── node_modules/  — Runtime dependencies (generated by `npm install`)
└── server/            — Reserved for future FastAPI backend
    └── README.md      — Describes backend reservation
```

## Running the Frontend

All frontend commands are run from `client/`:

```bash
# Development server with HMR
cd client
npm run dev

# Production build (TypeScript check + Vite build)
npm run build

# Lint check
npm run lint

# Preview production build
npm run preview
```

## Project Scope

- **Frontend only.** The `client/` directory contains the complete Orvethiq AI chat frontend built with React 19, TypeScript, and Vitest.
- **Mock data strategy.** Use mock data and mock services until the frontend is complete. Do not wait for backend endpoints.
- **Clean service interfaces.** Types and service adapters in `client/src/types/` and `client/src/services/` are prepared for later FastAPI connection.
- **No real authentication yet.** Auth screens and frontend validation only — no JWT, no token storage.

## Backend Reservation

The `server/` directory is reserved for the future Python/FastAPI backend. Do not implement the backend or initialize a separate Python project yet. See `server/README.md` for details.

## Directory Moves

The original frontend files were moved from the repository root into `client/` to create a monorepo structure with `client/` for the frontend and `server/` for the future backend.
